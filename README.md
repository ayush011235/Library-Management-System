# 📚 Library Management System

A console-based **Library Management System** developed using **Python**, **Object-Oriented Programming (OOP)**, and **Microsoft SQL Server**. This application helps librarians efficiently manage books, members, and borrowing transactions.

---

## ✨ Features

- 🔐 User Authentication
- 📖 Add, View, Search, Update, and Delete Books
- 👤 Add, View, Search, Update, and Delete Members
- 📚 Borrow Books
- 🔄 Return Books
- 📊 Report Generation
- ✅ Input Validation
- 🗄️ Microsoft SQL Server Database Integration

## 🚀 How to Run

1. Clone the repository.
2. Install Python.
3. Install the required package:

```bash
pip install pyodbc
```

4. Create the SQL Server database.
5. Update the database connection in `database.py`.
6. Run:

```bash
python main.py
```
